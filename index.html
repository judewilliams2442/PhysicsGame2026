-- Game Rules --

  • All variables are randomly assigned numerical values for each player at the start of a round.
  • Each player draws from a shared card pool.
  • Players must form an equation using their cards that either:
    • Has exactly one unknown variable, OR
    • Uses all known variables in a valid equation.
  • Players can:
    • Solve for the unknown variable, OR
    • Choose any variable in a fully-known equation to calculate (for strategic advantage).
  • Players secretly choose to DRAW (continue building) or STOP (lock in their result).
  • If both players choose DRAW, the round continues.
  • If one or both players choose STOP, the round ends.
  • The player with the higher final calculated value wins the round.
  • After each round:
    • All cards are returned to the pool.
    • All variables are re-randomized.
